Unity vydalo oficiální plugin pro Grok Build – sadu 30+ skills od Unity týmů pro AI coding agenty (Claude Code, Codex, Grok Build). Zahrnuje např. 2D, UI, fyziku, IAP (In-App Purchases).

## Proč je to důležité

Unity oficiálně podporuje AI coding nástroje – skills jsou návody pro AI agenty, jak používat Unity API a nástroje. To znamená, že AI může generovat Unity kód s vyšší přesností a bez hallucinací typických pro obecné LLM. Pro začátečníky je to možnost rychleji prototypovat a učit se – AI ukáže, jak správně použít Unity komponenty. Plugin podporuje Claude Code, Codex a Grok Build, takže je platformě-agnostický.
