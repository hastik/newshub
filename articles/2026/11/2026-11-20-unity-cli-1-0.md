Na Unite Tokyo vyšly z bety Unity CLI 1.0 a balíček Pipeline, přes který CLI ovládá běžící Editor. Od července CLI použilo přes 350 000 uživatelů a spustilo přes 600 milionů příkazů, z toho asi 98 % coding agenti a automatizace. Novinky: `unity setup` jedním příkazem nainstaluje oficiální plugin pro Claude Code, Codex, Grok Build nebo Google Antigravity, CLI umí odkliknout skrytý dialog, na kterém Editor visí, `unity build --target` staví v otevřeném Editoru a `unity projects audit` udělá kontrolu projektu. Výstupy mají jednotný JSON a příkazy zůstanou kompatibilní napříč 1.x.

## Proč je to důležité

Navazuje na oficiální Unity plugin pro AI agenty z října. Unity se tím stává enginem, se kterým agent pracuje „naživo“: otevře projekt, spustí Play mode a přečte výsledek. Pro začátečníka to znamená reálnou možnost nechat agenta stavět a testovat prototyp v Unity místo kopírování kódu z chatu. Kdo zůstává u Godotu, má aspoň jasný obrázek, kam se nástroje posouvají.
