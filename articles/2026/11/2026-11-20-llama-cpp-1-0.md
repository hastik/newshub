Po 3,5 roku vývoje vyšly llama.cpp v1.0.0 a ggml v1.0.0. Od teď platí semantické verzování: rozbití veřejného C API znamená novou major verzi, nové funkce a podpora modelů jen minor. Projekt podporuje přes 150 variant architektur modelů a je k dispozici přes Homebrew, winget, Docker, Debian, conda-forge a další. Tým z Hugging Face nabízí i desktopové aplikace pro macOS a Windows.

## Proč je to důležité

llama.cpp je motor pod většinou nástrojů pro lokální modely (LM Studio, Ollama a další). Stabilní API znamená méně rozbitých integrací při aktualizacích a víc důvěry v nasazení modelů na vlastním hardwaru, třeba tam, kde data nesmí opustit firmu. Je to dobrý okamžik, kdy si lokální AI znovu vyzkoušet.
