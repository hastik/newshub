## Kontext

Ondřej je začátečník v oblasti game developmentu, experimentuje s idle/clicker hrami a shootery. Tato kategorie sleduje konkrétní nástroje a autory v game dev oblasti, které Ondřej individuálně monitoruje pro inspiraci a vzdělávání. Každý nástroj nebo autor má vlastní podsekci se zdroji.

**Důležité**: Každý článek musí obsahovat tag identifikující konkrétní nástroj nebo autora (např. `shallot`, `dylan-ebert`).

## Sledované nástroje a autoři

### Shallot Engine

Moderní lightweight herní engine od Dylana Eberta, který by Ondřej mohl využít pro vlastní projekty.

**Zdroje**:
- GitHub: github.com/dylanebert/shallot (releases, tags, commits, PRs, issues)
- Changelog: github.com/dylanebert/shallot/blob/v0.10.2/CHANGELOG.md (v0.10.2 je referenční bod; v praxi číst CHANGELOG.md na default branch)

**Co hledat**:
- Nová vydání a tagy
- Changelog – novinky, přidané funkce, breaking changes
- Notable commits a významné PR
- GitHub issues označené jako milestones
- Příklady a demo projekty

### Dylan Ebert (autor)

Dylan Ebert je autor Shallot enginu a game dev content creator. Sledujeme všechen jeho game-dev obsah, nejen Shallot.

**Zdroje**:
- YouTube: youtube.com/@IndividualKex (devlogy, tutoriály, game dev videa)
- X/Twitter: x.com/dylan_ebert_ (oznámení, updates, myšlenky)

**Co hledat**:
- Devlogy a tutoriály
- Game dev tipy a workflow
- Oznámení o nových projektech
- Technické články a myšlenky

## Co ignorovat

- Osobní příspěvky nesouvisející s game developmentem
- Off-topic diskuze v GitHub issues
- Příspěvky o jiných tématech mimo game dev
